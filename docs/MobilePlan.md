  MoodFM 移动端适配计划（方案 B · Mobile-First）

  核心结论： 设计稿每个页面都已写好 isMobile 分支（390px 手机 / 1440px 桌面），两套值明确。我们要做的是把这些 isMobile ?
   A : B 逻辑转化为 CSS @media (min-width: 768px) 规则，而不是用 JS 判断。
